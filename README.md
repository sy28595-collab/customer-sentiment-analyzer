Customer Sentiment Analyzer

A simple customer feedback application that analyzes written reviews and classifies them as Positive, Neutral, or Negative.

Project Overview

This project is built to understand customer sentiment from feedback messages.

The system uses two approaches:

VADER Lexicon as the baseline sentiment analyzer.

TF-IDF + Logistic Regression as the machine learning model.

Customer reviews are analyzed using VADER and stored in a SQLite database. An Admin dashboard shows customer feedback, sentiment distribution, and model evaluation results.

Features

Customer feedback form

Positive, Neutral, and Negative sentiment detection

Emoji-based customer rating

Sentiment Analysis

VADER is used as the baseline sentiment analyzer.

VADER calculates a compound sentiment score.

The project uses these thresholds:

Compound Score >= 0.05
→ Positive

Compound Score <= -0.05
→ Negative

Between -0.05 and 0.05
→ Neutral

Machine Learning Model

The machine learning model uses:

TF-IDF
+
Logistic Regression

TF-IDF converts customer messages into numerical features.

Logistic Regression then learns the relationship between these features and the sentiment labels generated by VADER.

Dataset

The project uses 300 customer messages.

The dataset is divided into:

Training Data: 240 messages
Testing Data: 60 messages

VADER-generated sentiment labels are used for the machine learning evaluation.

Model Evaluation

The model is evaluated using:

Accuracy

Precision

Recall

F1 Score

Confusion Matrix

The current test accuracy is approximately 71.67%.

This score represents agreement with the VADER-generated labels. It is not an independent measurement against human-verified sentiment labels.

How to Run

1. Create virtual environment

python -m venv .venv

2. Activate virtual environment

Windows:

.venv\Scripts\activate

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run app/app.py

The application will open in the browser.

Application

The application has two main sections:

Customer Feedback

Customers can:

Select their experience using an emoji.

Write an optional review.

Submit their feedback.

The customer does not see the technical sentiment analysis or model scores.

Admin Dashboard

The Admin dashboard provides:

Total review count

Positive, Neutral, and Negative counts

Sentiment distribution

Customer feedback

Search and filtering

Model performance

Classification report

Confusion matrix

VADER vs Logistic Regression comparison

Important Note

The current machine learning evaluation uses VADER-generated labels because the initial dataset does not contain independent human-verified sentiment labels.

Therefore, the reported ML accuracy should be interpreted as agreement with the VADER baseline rather than real-world sentiment accuracy.
