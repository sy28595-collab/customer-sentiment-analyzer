# Customer Sentiment Analyzer

A small customer feedback application built to understand how customers feel about a product or service.

The application analyzes written reviews and classifies them as Positive, Neutral, or Negative. It also includes an Admin dashboard where the collected feedback and model evaluation results can be viewed.

## Project Overview

The project uses two approaches for sentiment analysis:

- **VADER** is used as the baseline sentiment analyzer for customer reviews.
- **TF-IDF + Logistic Regression** is used as a machine learning model for evaluation.

Customer reviews are analyzed using VADER and stored in a SQLite database. The Admin dashboard shows the collected feedback, sentiment distribution, and machine learning evaluation results.

## Sentiment Analysis

VADER is used as the baseline sentiment analyzer.

It generates a compound sentiment score for each review.

The project uses these thresholds:

- Compound score >= 0.05 → Positive
- Compound score <= -0.05 → Negative
- Between -0.05 and 0.05 → Neutral

## Machine Learning Model

The machine learning part uses TF-IDF with Logistic Regression.

TF-IDF converts customer messages into numerical features. Logistic Regression then learns patterns from these features using the sentiment labels generated by VADER.

The model uses:

- TF-IDF with unigram and bigram features
- Sublinear TF scaling
- Logistic Regression
- Balanced class weights

## Dataset

The project uses 300 customer messages.

The dataset is divided into:

- Training data: 240 messages
- Testing data: 60 messages

The original dataset does not contain independent human-verified sentiment labels, so VADER-generated labels are used for the machine learning evaluation.

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

The current test accuracy is **73.33%**.

This result represents agreement between the machine learning model and the VADER-generated labels. It should not be treated as independent real-world sentiment accuracy because the evaluation labels were generated by VADER rather than human annotators.

## Application

The application has two main sections.

### Customer Feedback

Customers can:

- Select their experience using an emoji.
- Write an optional review.
- Submit their feedback.

The customer only interacts with the feedback form. Technical sentiment scores and model information are kept in the Admin dashboard.

### Admin Dashboard

The Admin dashboard provides:

- Total review count
- Positive, Neutral, and Negative counts
- Sentiment distribution
- Customer feedback
- Search and filtering
- Model performance
- Classification report
- Confusion matrix
- VADER vs Logistic Regression comparison
